# IMA Studio Landing Page

一个使用 React + TypeScript + Vite + OGL (WebGL) 构建的现代化落地页。

## 特性

- 🎨 **WebGL 渐变背景** - 使用 OGL 实现的动态渐变百叶窗效果
- ⚡ **Vite 构建** - 极速的开发体验和优化的生产构建
- 🔷 **TypeScript** - 类型安全的代码
- 📱 **响应式设计** - 适配各种屏幕尺寸

## 技术栈

- React 18
- TypeScript
- Vite 5
- OGL (WebGL 渲染库)

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```
